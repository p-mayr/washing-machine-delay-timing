# washing-machine-delay-timing
Calculation helper to set the delay timer on a washing machine so it finishes at the required time.

## Features
**Input**
- Current time (defaults to now)
- Program duration (preset selection or custom input)
- Target finish time

**Output**
- Delay setting for the washing machine ("start in X h", full hours, 0–24 h)

## Usage
Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server
```
